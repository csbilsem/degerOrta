# degerOrta

**Değer Orta** — ortalama, medyan, mod ve açıklık bulmaya dayalı bir eğitsel oyun.

`index.html` dosyasını tarayıcıda açmanız yeterli; kurulum gerekmez.

- 3 seviye, her seviyede 10 soru, 3 can
- Süreye ve doğru seriye göre puan
- Yanlış cevapta çözüm açıklaması
- Seviye başına en iyi skor tarayıcıda saklanır
